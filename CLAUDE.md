## Project Overview

This is a custom **Shopify Liquid theme** (Empire v9.1.1 by Pixel Union, customized for Mule brand). It is a pure Shopify theme with no Node.js build process — CSS and JS files in `/assets/` are pre-compiled and deployed directly.

## Shopify CLI Commands

```bash
# Start local development server (live preview synced to a Shopify store)
shopify theme dev --store <store-url>

# Push theme to Shopify
shopify theme push

# Pull latest theme from Shopify
shopify theme pull

# Check theme for errors
shopify theme check
```

There is no `package.json`, no npm/yarn build step, and no test suite. Development happens by editing files and using the Shopify CLI to preview.

## Architecture

### Template Layer (`/templates/`)
JSON files that define which sections compose each page. Templates reference section IDs; they are the composition layer, not rendering logic. Highly product-specific templates follow the pattern `product.<product-name>.json`.

### Sections (`/sections/`)
Liquid files that render discrete page blocks. Sections contain their own schema (settings, blocks, presets). Two categories:
- **`static-*`** sections: Always rendered (header, footer, announcement bar) — configured in `/sections/header-group.json` and `/sections/footer-group.json`
- **`dynamic-*`** sections: Added via the theme editor to pages

### Snippets (`/snippets/`)
Reusable Liquid partials rendered via `{% render 'snippet-name' %}`. Product display components (grid items, galleries, pricing, badges) live here.

### Assets (`/assets/`)
Pre-compiled CSS and JS. Key files:
- `empire.js` / `empire.js.liquid` — main JS bundle (~1.4MB, webpack-compiled upstream)
- `theme.css` / `theme.css.liquid` — base theme styles with font definitions
- Component-specific CSS/JS files (e.g., `product-slider.css`, `mobile-workshop.js`) are custom additions

### Layout (`/layout/`)
- `theme.liquid` — the root HTML shell; contains GTM, ad tracking pixels (TTD, Flashtalking, Facebook), and a custom ATC-redirect script
- `quickshop.liquid`, `password.liquid`, `none.liquid` — alternate layouts

### Configuration (`/config/`)
- `settings_schema.json` — defines all theme editor settings (colors, typography, layout, product display)
- `settings_data.json` — stores current theme settings values (managed by Shopify admin)

### Locales (`/locales/`)
Translation strings in JSON. `en.default.json` is the source of truth. Schema files (e.g., `en.default.schema.json`) contain section setting labels shown in the theme editor.

## Key Conventions

- **Liquid rendering**: Use `{% render %}` (not `{% include %}`) for snippets — this is the Shopify modern standard that scopes variables.
- **Section settings**: Settings defined in the `{% schema %}` tag at the bottom of each section file are accessed via `section.settings.<key>`.
- **`header-group.json` and `footer-group.json`**: These files are flagged as auto-generated by Shopify admin — changes may be overwritten. Edit the underlying `static-*` sections instead.
- **Custom CSS/JS**: Add new feature-specific files to `/assets/` and reference them from the relevant section or layout file. Do not modify `empire.js` directly.
- **Product templates**: Many product templates are product-specific (e.g., `product.garage-fan-xl.json`). The default is `product.json`.
